# SPEC — 优化播放器整体页面布局

> 创建时间：2026-11-04
> 需求级别：L1（Standard）

## 1. 用户原始诉求

> “中间文字部分占用过高位置，导致播放窗口高度不足而缩小，请优化整体页面布局（含 Web 端）”

## 2. 本次做什么

- 目标：压缩标题信息区和控制栏，把垂直空间让给视频窗口。
- 影响范围：小程序英语播放器与 Web 英语播放器。
- 预期改动文件/模块：`miniprogram/pages/player/player.wxml`、`player.wxss`、`english/index.html`、`english/css/style.css`、相关测试。

## 3. 本次不做什么

- 不改变媒体数据、播放流程、拖动逻辑、缓存策略和视觉主题。
- 不修改古诗页面布局，不新增 API、路由、依赖或生产配置。

## 4. 风险分类

| 检查项 | 结论 | 说明 |
|--------|------|------|
| `classify-change-risk.sh` | UPGRADE_L1 | 当前工作树改动文件数超过 3 |
| Agent 语义复核 | 低风险 | 纯展示层布局，不触碰 API、数据、权限或发布 |
| 推荐流程 | L1 | 使用 SPEC + Plan + 自动测试 + Web 验收 |

## 5. 验收条件

| 编号 | 验收条件 | 验证方式 |
|------|----------|----------|
| AC-01 | 标题信息区最多两行，不再堆叠成高区块 | DOM/CSS 检查、截图 |
| AC-02 | 视频窗口获得更多可用高度 | 移动视口尺寸检查 |
| AC-03 | Web 与小程序信息层级和间距一致 | 对照检查 |
| AC-04 | 播放、拖动和缓存逻辑不变 | 全量测试 |

## 6. 轻量验证计划

- 自动验证：`node --test tests/*.test.js`。
- 手工验证：移动视口打开视频，检查标题区、视频区尺寸并截图。
- 预期 evidence：测试输出、浏览器尺寸数据与截图。
