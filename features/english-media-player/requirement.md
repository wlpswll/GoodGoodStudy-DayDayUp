## 1. 需求背景

- 当前业务背景：同仓库的古诗页（`gushi/`）用纸色封面、侧滑目录和底部播放条听朗读。本地 `english/` 目前只有一年级上册跟读音视频，没有播放页。
- 触发原因：需要一个英语学习媒体播放器，交互参考古诗目录。
- 现状问题：媒体散落在两个文件夹里，跟读音频目录中还夹着一个 mp4，没有统一入口，也没有断点。

## 2. 目标与成功标准

- 业务目标：孩子或家长打开页面就能按课继续听、看。
- 用户目标：先看见按类型分开的列表，点一项就播放该项；下次打开还停在上次的媒体和时间；倍速从 1 倍起可选。
- 成功指标：列表不把音频和视频混在同一组；刷新后媒体 id 与进度一致；默认倍速为 1。

## 3. 用户角色与使用场景

- 用户角色：使用一年级上册英语跟读材料的学习者和家长。
- 使用入口：`english/index.html`，通过 HTTP 静态服务打开。
- 使用路径：打开页面 → 若有上次记录则进入该媒体并定位时间 → 否则浏览分组列表 → 点视频或音频播放 → 可拖动进度、切换倍速 → 离开后再打开仍恢复。
- 关键场景：音频目录里的 mp4 必须出现在视频组；只有音频的条目出现在音频组。

## 4. 功能需求

| 编号 | 功能点 | 描述 | 输入 | 输出 | 规则 | 异常处理 |
|------|--------|------|------|------|------|----------|
| FR-01 | 读取媒体列表 | 扫描英语目录生成清单，页面读取清单 | 媒体文件 | 分组列表 | 忽略隐藏文件和页面自身目录 | 清单加载失败时提示通过 HTTP 打开 |
| FR-02 | 音视频分类 | 音频、视频分开，组内再按所在文件夹分组，分类标题可折叠 | 扩展名、父目录 | 两个区块 | 以扩展名而不是文件夹名决定类型；点分类标题收起或展开该组 | 不认识的扩展名不进列表 |
| FR-03 | 点选播放 | 点击列表项播放对应文件 | 媒体 id | 音频或视频画面 | 同一时刻只播当前项；上一项、下一项只在同类型内移动 | 浏览器不能解码时给出提示 |
| FR-04 | 常见格式 | 支持常见音视频扩展名 | 文件名 | 类型 | 音频 mp3/m4a/aac/wav/ogg/oga/flac/opus/weba；视频 mp4/m4v/webm/ogv/mov/mkv。大小写不敏感 | 不支持的格式不展示 |
| FR-05 | 断点与记忆 | 记住上次媒体、时间和倍速；打开页面时恢复 | 播放进度 | 恢复后的播放器 | 默认倍速 1；快结束则下次从 0 开始但仍打开该媒体 | 记录里的文件已不在清单中时回到列表，倍速仍可用 |
| FR-06 | 倍速选择 | 可选倍速，而不是只能循环一个隐藏值 | 0.5 / 0.75 / 1 / 1.25 / 1.5 / 2 | 当前倍速 | 缺省和非法值都是 1 | 设置失败时保持原倍速显示与状态一致 |
| FR-07 | 小程序预留 | 进度字段和播放动作可被小程序页面复用 | 同一清单与进度对象 | 适配器与示例页 | 存储键和字段固定；音频走 InnerAudioContext，视频走 VideoContext | 小程序里视频当前时间由组件回调写入 |
| FR-08 | 视频系统全屏 | 视频用浏览器系统全屏播放，再退出 | 顶部全屏图标 | 系统全屏中的视频和控制条 | 只对视频提供；调用 Fullscreen API；iPhone 走系统视频全屏；接口被拒绝时仍铺满页面；Esc 或再点图标退出 | 全屏被拒绝时保留页面内铺满 |

## 5. 涉及的接口/数据定义

本需求不涉及服务端接口。本地数据契约如下。

| 定义文件 | 结构体/类型 | 相关字段 | 用途 |
|----------|------------|----------|------|
| `english/data/media.json` | 媒体清单 | `items[].id/title/kind/ext/folder/src` | 页面与小程序共用的列表。`id` 等于相对路径 |
| `english/js/progress.js` | 进度快照 | `version/mediaId/kind/currentTime/playbackRate/updatedAt` | 键名 `english-player-progress-v1` |

## 6. 非功能需求

- 性能：列表一次渲染；进度写入最多约每秒一次，暂停、拖动和离开页面时立即写。
- 安全：只读本地媒体，进度留在本机存储，不上传。
- 兼容性：布局沿用古诗页的纸色、安全区和底部控制条；脚本保留 `sharecode` 透传。小程序示例不依赖 DOM。
- 可维护性：分组、倍速和断点换算不依赖页面，便于测试和迁到小程序。

## 7. 范围边界

- **本次要做：** 播放页、目录扫描、分组列表、播放控制、断点、倍速、小程序适配示例、自动测试。
- **本次不做：** 古诗页改动、用户系统、下载管理、转码、歌词或课文同步高亮。
- **默认假设：** 现有文件名就是课节标题；用本地 HTTP 打开页面；小程序正式媒体地址以后由业务填 CDN 前缀。
- **依赖条件：** 浏览器能解码 mp3、m4a、mp4。mov/mkv 等允许列出，不能播时提示。

## 8. 验收标准

| 编号 | 验收条件 | 验证方式 |
|------|----------|----------|
| AC-01 | 页面展示分组列表，视频与音频不是同一组；组内再按文件夹分 | 浏览器查看列表；单测检查夹在音频目录中的 mp4 进入视频组 |
| AC-02 | 点击某一项后播放该项，而不是另一项 | 浏览器点播，核对标题与元素地址 |
| AC-03 | 常见扩展名能被识别，无法识别的文件不出现 | `node --test` |
| AC-04 | 再次打开页面时选中上次媒体，并把进度恢复到上次时间；每一课各自记住时间，切走再回来仍从该课上次位置继续 | 播放后刷新；U1 播到中途后改播另一课，再点回 U1，核对 currentTime |
| AC-05 | 未选择过倍速时为 1；可改为列表中的其他倍速 | 单测默认值；浏览器点选倍速后看 `playbackRate` |
| AC-06 | 播放结束再打开时仍进入该媒体，进度从开头重新开始 | 单测 `clampResumeTime` |
| AC-07 | 小程序适配器使用同一进度字段，并能对音频上下文执行播放、暂停、跳转和倍速 | 阅读适配器并用假 wx 对象做单测 |
| AC-08 | 重新扫描目录后，清单与磁盘上的受支持文件一致 | `build-catalog.py` 后 `node --test` |
| AC-09 | 播放视频时顶部有全屏图标，点击后请求浏览器系统全屏，再退出；音频没有这个按钮 | 浏览器点击「全屏」和「退出全屏」 |
| AC-10 | 目录里的分类标题可以折叠和展开 | 浏览器点击分类标题，核对课节是否收起再出现 |
