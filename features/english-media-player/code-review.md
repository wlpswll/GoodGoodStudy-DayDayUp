## 代码评审

| 项 | 结论 | 说明 |
|----|------|------|
| AC-01 音视频分开 | 通过 | `groupCatalog` 先按 kind，再按文件夹。音频目录里的 mp4 只出现在视频组。 |
| AC-02 点选即播 | 通过 | 列表按钮带媒体 id，打开时设置对应元素的 src。上一首、下一首只用同一类型队列。 |
| AC-03 常见格式 | 通过 | 扩展名白名单集中在 catalog.js，扫描脚本使用同一组。 |
| AC-04 断点 | 通过 | 打开页面读取 `english-player-progress-v1`。进度条回写不再把正在播放的位置写成 0。 |
| AC-05 默认 1 倍 | 通过 | 未记录或非法倍速都回到 1。可选 0.5、0.75、1、1.25、1.5、2。 |
| AC-06 播完从头 | 通过 | `clampResumeTime` 在距结尾 0.75 秒内返回 0。 |
| AC-07 小程序契约 | 通过 | 适配器用假 wx 测过播放、跳转、倍速和同一份快照。示例页不打包视频。 |
| AC-08 清单一致 | 通过 | 测试把磁盘上的受支持文件和 media.json 逐条对比。 |

没有必须修改项。已知限制：冷门容器格式只提示、不转码；小程序要另填媒体前缀。
